# System Charter

## Intent

I want this system to carry the meaning of simple input becoming visible behavior.

## Constraints

- One signal controls the system.
- One visual form carries the behavior.
- No external libraries are used.

## Tensions

- Input vs. response
- Control vs. movement

## Taste Vow

I will avoid unnecessary effects and overproduction.

## Template Rules

Signal: mouse X position

Parameter: circle radius

Behavior: the circle pulses over time

Readability test: moving the mouse from left to right should clearly change the circle's size within 5 seconds.
