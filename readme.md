# Reusable Studio Engine

This engine is a reusable starting point for building simple interactive Canvas projects.

## How to Run Locally

Open `index.html` in a browser, or use a simple local server through VS Code.

## How to Deploy

I use **Netlify** to deploy the project. The GitHub repository is connected to Netlify, so the project can be published as a shareable public link.

## How I Use This to Start Projects

When I start a new project, I first define what I want the system to mean and write down my constraints. Then I sketch the system in words before asking AI for technical help. I build the smallest working version first, test the main behavior, and make changes only when they improve the idea. Once the system works and the meaning is clear, I polish it and deploy it.
